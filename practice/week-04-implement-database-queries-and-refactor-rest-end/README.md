# Implement Database Queries and Refactor REST Endpoints

## Task Brief
Build ORM queries for user-task relationships; refactor Flask CRUD endpoints to use SQLAlchemy instead of in-memory storage.

## Scenario
Refactor your REST endpoints to query the database. Replace in-memory task lists with SQLAlchemy ORM queries and proper HTTP status codes.

## Deliverables
- Refactored CRUD endpoints using ORM
- HTTP status code responses (200, 201, 404, 400)

## Success Criteria
- All CRUD endpoints use SQLAlchemy queries
- Correct HTTP status codes returned
