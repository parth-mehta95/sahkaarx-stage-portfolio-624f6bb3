# Debug Authentication Flow with Breakpoints

## Task Brief
Set breakpoints in login and registration code; step through execution to verify password hashing and user validation work correctly.

## Scenario
Debug your authentication flow to ensure password hashing and user lookup work correctly. Use breakpoints to trace execution.

## Deliverables
- Breakpoints set in auth routes
- Debug session walkthrough notes

## Success Criteria
- Breakpoints pause at key auth steps
- Password hashing verified in debugger
