# Implement User Registration & Login with Debugging

## Task Brief
Add registration and login endpoints with password hashing; set breakpoints to debug auth flow.

## Scenario
Your team needs secure user registration and login. Implement endpoints with hashed passwords and debug using breakpoints.

## Deliverables
- Flask auth endpoints in app.py
- User registration and login routes

## Success Criteria
- Registration creates user with hashed password
- Login validates credentials correctly
