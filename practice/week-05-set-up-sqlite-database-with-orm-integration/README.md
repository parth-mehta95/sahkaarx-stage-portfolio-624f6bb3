# Set Up SQLite Database with ORM Integration

## Task Brief
Design and implement SQLite schema for users and tasks; integrate SQLAlchemy ORM into Flask app for data persistence.

## Scenario
Your team needs persistent data storage. Set up SQLite with proper schema and ORM models for user and task data.

## Deliverables
- models.py with SQLAlchemy User and Task models
- Database initialization script

## Success Criteria
- Schema supports user authentication and task CRUD
- ORM queries replace in-memory storage
