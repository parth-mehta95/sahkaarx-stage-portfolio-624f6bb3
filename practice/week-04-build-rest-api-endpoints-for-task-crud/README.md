# Build REST API Endpoints for Task CRUD

## Task Brief
Develop Flask endpoints for Create, Read, Update, Delete task operations with proper HTTP methods and status codes.

## Scenario
Your team needs complete task CRUD endpoints. Build Flask routes using HTTP methods and return JSON responses.

## Deliverables
- Flask routes in app.py for task CRUD
- JSON response handlers

## Success Criteria
- POST /tasks creates task and returns 201
- GET /tasks returns all tasks with 200
