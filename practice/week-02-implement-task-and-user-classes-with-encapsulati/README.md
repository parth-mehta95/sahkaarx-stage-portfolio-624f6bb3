# Implement Task and User Classes with Encapsulation

## Task Brief
Create Task and User classes with private attributes and methods; add task creation and retrieval functionality to your Flask app.

## Scenario
Your team needs reusable Task and User classes for the task manager. Implement encapsulation with private attributes.

## Deliverables
- Task class with private attributes
- User class with task methods

## Success Criteria
- Classes use private attributes (_name, _id)
- Task creation and retrieval methods work
