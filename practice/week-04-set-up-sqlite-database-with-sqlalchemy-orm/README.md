# Set Up SQLite Database with SQLAlchemy ORM

## Task Brief
Integrate SQLAlchemy ORM into Flask app; design and implement SQLite schema for users and tasks with proper relationships.

## Scenario
Your team needs persistent storage for the task manager. Set up SQLite with SQLAlchemy ORM models and relationships.

## Deliverables
- SQLAlchemy User and Task models
- SQLite database schema with foreign keys

## Success Criteria
- Models define user-task relationships
- Foreign keys enforce referential integrity
