# Configure Git Repository with Feature Branches

## Task Brief
Set up meaningful commit history and create feature branches for authentication and API modules in your task manager.

## Scenario
Your team needs clean Git history and feature branches. Organize your Task Manager repo with meaningful commits and branches.

## Deliverables
- Feature branches for auth and API
- Meaningful commit history

## Success Criteria
- At least 3 feature branches created
- Commits follow conventional format
